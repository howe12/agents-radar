## 三、趋势信号分析

今日 AI 开源生态的最强信号是 **「Agent Skills 化」** 的全面到来。Trending 榜单前 10 名中，超过一半项目围绕 Agent Skills 展开——archify（架构图生成）、scientific-agent-skills（科研）、OpenMontage（视频制作）、OpenMAIC（多 Agent 教学）—— 这些项目都不再是 Agent 框架本身，而是面向 Claude Code / Codex / Cursor 等 Agent 运行时的 **可插拔技能模块**。这标志着 Agent 生态从「LangChain 式框架之争」过渡到「App Store 式技能市场之争」，生态重心已从底层 SDK 上移到应用层技能封装。

第二个明显信号是 **本地化 AI 一体机** 的崛起。Osmantic/ODS（+35 today）、open-webui（150k 总星）、K-Dense-AI 的 165+ 离线科研技能共同指向「去云化、单机即 AI 中心」的方向，与 Kimi-K2.6、GLM-5.2、MiniMax 等开源大模型的本地运行需求形成共振。

第三，**Agent 模型路由与成本优化** 成为新热点。workweave/router（<50ms 路由、成本降 40-70%）搭配 headroomlabs-ai/headroom（token 压缩 60-95%）与 affaan-m/ECC（harness 性能优化），反映出 Agent 落地正从「能不能跑」转向「能不能便宜跑」。

最后，**Sana、IsaacLab、Mooncake** 等推理/物理仿真基础设施持续保持高活跃度，配合 Isaac Lab / MuJoCo 等具身智能底座，叠加 THU-MAIC 推出多 Agent 教学产品，显示学术界与产业界在 Agent + 具身智能交叉点的协同加速。
