## 三、趋势信号分析

今日 AI 开源热度高度集中在 **"Agent Harness / Skill 工具链"** 这一新兴细分赛道。Trending 榜单上 `openwork`、`last30days-skill`、`reverse-skill`、`jcode` 等项目几乎清一色围绕 Claude Code / Codex / Cursor 等 AI 编程客户端展开，本质上是为大模型 Agent 提供"上下文工程、Token 经济、记忆持久化、技能路由"的中间层。值得关注的是，**"caveman 风格" Token 压缩（`JuliusBrussee/caveman`）和"知识图谱化代码库"（`Graphify-Labs/graphify`）** 等极简理念正在形成新流派，意味着开发者社区已从"卷模型"转向"卷 Agent 运行时效率"。

与此同时，**RAG 生态在向"持久记忆 + 向量无关推理"方向演进**：`claude-mem`、`mem0` 让 Agent 跨会话具备连续记忆，`PageIndex` 则挑战了传统向量检索路线，`headroom` 专注上下文压缩。三者共同指向 **"长上下文时代的 Agent 工程化"**。模型层面，今日 Ollama 描述中同时出现 Kimi-K2.6、GLM-5.2、MiniMax、DeepSeek、Qwen 多家国产模型，反映出**国产开源大模型矩阵已成主流接入对象**——这一变化与近期国内大模型密集迭代的节奏高度同步。
